# Working_With_Chest_XRays_Images
This project focuses on automatic classification of chest X-ray images to detect Pneumonia using Deep Learning techniques.
Chest X-rays are one of the most commonly used diagnostic tools in medical imaging, and automating their analysis can assist doctors in faster and more accurate diagnosis.

The model is trained using Convolutional Neural Networks (CNNs) to distinguish between Normal lungs and pleural effussion lungs.
